## 1. 原则

| 入口 | 只回答一个问题 | 取代 |
|---|---|---|
| 服务器 | 现在能交到哪里？谁在占用？ | 原"作业"页 |
| 研究（进展 / 计算链 / 全部 Attempt） | 研究到哪里了？还缺什么？ | 原"Study"概览、Attempt 表 |
| 结果（报告 / 比较） | 结论是什么？几个候选怎么比？ | 原"分析"入口、快速比较、结构对比 |
| 证据（文件库 / 来源关系 / 研究说明） | 依据在哪里？ | 原"文件"四个标签和"其他分析文件" |
| 使用说明（右上角） | 每页能看到什么、怎么用、数据从哪来 | 新增 |

- 组织方式从"Attempt 和文件"改为"对象 → 计算链 → 采用结果 → 比较 → 证据"。
- 每个数字都写明口径；"未知"不当作 0；工具检查完成不用绿色。
- 去掉常驻的 Study 侧栏，改为上下文栏里的"Study ▾"切换器（研究 / 验证与测试分组，可筛选）。窄屏下不再把正文挤到后面。

## 2. 各页规格

**服务器**（细节见 T114/T115 的讨论记录）
- 顶部每台服务器一张卡片，按提交优先级排（default → newhpc → scnet → scnet-初筛）：核数、内存各一条分段进度条（本人深色 / 他人浅色 / 空闲 / 未知斜纹）；作业数；本人用量与 ag 上限一行；共享上限的入口要注明。
- 下方是详情区，用标签页切换，点卡片也能切换：有警告时置顶显示；作业表按"运行中 / 排队中"分组，每组标明作业数和核数；本人作业置顶并高亮，带 Attempt 链接和进度；有"只看本人"开关；Slurm 入口只列本人明细，其他人只给一行汇总。
- "节点与队列""限额、档位与存储"做成折叠区，默认收起，标题行带摘要。"刚结束待取回"放在页面底部。
- 删除：7 列总览表、旧的容量卡片、底部按集群折叠的详情区、跨集群混排的作业表。

**研究 · 进展**
- 四个数字：在跑、待取回、待审阅、待签字，每个下面写口径（见第 3 节），点数字跳到对应列表。
- "还缺什么"是有序清单，合并下一步动作、待审阅、study.md 的"待你决定"和待签里程碑，每项都写来源并带跳转。
- "里程碑"每条给明确状态：已签 / 待签 / 未开始 / 无法识别（附行号和原文链接，不再笼统写"状态未明"）。
- "当前采用的结果"表：对象 · 电子态 → 结构 / 频率 / 能量各取自哪个 Attempt、登记的能量、依据报告、状态。
- "关键报告"按"已签 / 被采用结果引用 / 待签"挑选。"最近改动的文件"单独列出、默认折叠，并注明"不代表重要性"。
- 研究说明和进度日志放在折叠区；进度日志只显示最近 3 条。

**研究 · 计算链**
- 每行一个对象（构象 × 电子态）。链用小标签串起来，例如 CREST → Opt ✓ → Stable ✓ → Freq 0 虚频 → SP ✓，颜色表示状态。行内显示相对能量（参照可选，口径按 study 设置：E / E+ZPE / G）、状态（已采用 / 候选 / 待取回 / 历史）、审阅情况、"＋比较"。
- 展开一行，显示每一步的 Attempt、计算类型、**取自 route 的方法**、服务器、状态、关键事实、审阅情况。"方法依据"文本只在 Attempt 详情里显示。
- 筛选：电子态、计算类型、隐藏历史、只看需要我处理。"全部 Attempt"标签保留平铺表，增加"对象 · 电子态""计算"两列。

**结果 · 报告**
- 左侧目录按类别分组：正式结论 / 能量与排序 / 电子态检查 / 构象集合 / IRC / 热化学 / 阶段审阅 / 图与演示 / 其他。条目旁标明格式或状态。
- 正文：Markdown 表格、CSV、JSON 数组统一用可排序表格显示；表里的候选可以点，点了右侧显示结构预览；报告里引用的图片直接显示；本地相对链接可以点，打开证据库；过程报告顶部写明"当前采用的结论在哪一份"。
- "解析失败"只用于真正读不出来的文件，要给出行号和列号。

**结果 · 比较**
- 比较篮固定在研究页和结果页底部，跨页面保留，选择同时记在 URL 里。可以从计算链、采用结果表、报告表格加入。
- 一页里同时有：口径核对（逐项写一致 / 不同 / 缺失）、能量按层分开显示（Opt 层、SP 层、ΔE+ZPE）、ZPE、虚频、⟨S²⟩、关键几何参数、方法、审阅、来源；"只看有差异的行"开关；结构叠合（Kabsch，2–3 个）和原子对距离。
- 标题固定标"前端现场计算，非正式结果"。多重度不同时按电子态能差显示，不做布居。

**证据库**
- 文件库：每个文件只出现一次。左侧按类型分面（报告、表格、JSON、图片、HTML、结构、审阅意见、签字记录、输入与日志）和关联对象筛选，中间是列表（类型、关联对象、被谁引用、更新时间），右侧预览。
- 来源关系：一次只画一个对象的链及其分支（例如 S0 一行，T1 从 S0 的结构分出），框的颜色表示审阅状态。取代现有的圆形全图。
- 研究说明：study.md 原文，本地链接可以点。HTML 报告在隔离的只读框里显示，不运行脚本。

**使用说明**：目录加各页的三栏说明（能看到什么 / 常用操作 / 数据从哪来）、状态口径表、可操作模式说明、页面不做的事。

## 3. 数据口径（写单时逐条写进测试）

| 词 | 定义 |
|---|---|
| 在跑 | 本地状态为 running（含调度器排队） |
| 待取回 | 本地状态为 finished |
| 待审阅 | **采用结果或候选所用的** Attempt 已取回、facts 可读、review.md 为空。历史 Attempt 不计入（解决"待审 19"与"已完成"互相矛盾的问题） |
| 待签字 | 里程碑记录里明确写"待签" |
| 已采用 / 候选 / 历史 | 来自采用记录（见 B1）；没有记录时全部显示为"候选"，并提示"尚未登记采用结果" |
| 计算类型 | 从 route 关键词推出：Opt、TS、Freq、Stable、SP、IRC、Scan、CREST、xTB |
| 电子态 | 默认按多重度显示（1→S，3→T），登记记录里可以改名（如 S0、T1） |
| 计算链 | 按 parents 关系连成链；对象和构象名取自登记记录，没有就标"未登记" |
| 报告类别 | 先看 ag 的 schema，再看报告自己声明的 `kind`（Markdown 头部或 JSON 字段），再看登记记录；都没有就归入"其他" |
| 未知 | 采不到或格式不认识；显示斜纹或"未知"，不当作 0 |

## 4. 依赖

- **B1（后端，新）采用与对象登记**：新增 ag 命令，在 study 里写一份结构化登记文件（建议 schema `ag-catalog/1`，只追加，带日期和原话）。内容：对象（名称、电子态、构象）、Attempt 归属、每个对象当前采用的 Opt / Freq / SP、报告类别。写入前核对 Attempt 存在、已取回、facts 可读。不改动已有 manifest 和 facts。已签字的结论由负责人授权后才登记。
- **B2（后端，T114）**：在已定字段之外，补 PBS 提交时间 `qtime`（排队排序要用）。
- **F0（前端自带的本地后端）**：一个跨全部 study 的搜索索引，只索引编号、标签、对象、文件名；study 类型（研究 / 验证 / 测试）从 study.md 头部字段读，没有时按名称前缀 `val-`、`test-`、`demo-` 推断。
- **新依赖**：Markdown 表格需要 `remark-gfm`（react-markdown 官方插件）。只加这一个；表格排序自己实现，不引入表格库。

## 5. 建议的拆单顺序（编号写单时再定）

1. **T114 → T115**：服务器页整页重构（按第 2 节的服务器部分做）。
2. **前端 · 可找到、可读、可信**：报告渲染（GFM 表格、CSV / JSON 数组转表格、图片、本地链接）；JSON 数组不再报错；比较篮跨页保留；进展页四个数字的口径和里程碑状态；Study 切换器取代侧栏；全局搜索（F0）；使用说明页骨架（之后每张单更新自己那一节）。
3. **后端 B1** 采用与对象登记。
4. **前端 · 研究对象**：计算链页、进展页的"当前采用的结果"和"还缺什么"、关键报告的挑选规则（依赖 B1；没有 B1 时退回到按父子关系推导）。
5. **前端 · 比较与证据**：统一比较页（合并快速比较和结构对比）、证据库、来源关系图。

第 2 项不依赖后端，可以和 T114/T115 并行。第 4、5 项等 B1。

## 6. 不变的东西

只读边界、路径检查、大小上限；所有动作都经 ag；提交和取消的确认规则（AGENTS 3.4）；不出现"已验证"；旧链接要继续有效（旧标签页用 `replaceState` 跳到新位置）；现有浏览器测试覆盖的行为不能丢。

## 7. 验收

- 每张单截图 1440×860、1280×720、390×844 三个尺寸，全部用合成数据；不出现横向页面滚动（宽表格在自己的框里滚动）。
- 仓库是公开的：工单、PR、截图、夹具里不出现真实 study 名、Attempt 编号、物种代号、反应描述、用户名、主机名、节点名、分区或队列名。
