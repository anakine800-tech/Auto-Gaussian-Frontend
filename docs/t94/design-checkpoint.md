## 实现范围

- 全局令牌与十个统一组件已提供。FactGrid 用于输入参数，DataTable 用于关系表，
  ActionBar 用于日志翻页，Collapsible 记忆 Study 列表与输入哈希区块。
  Drawer 使用原生模态 dialog，支持 Esc、键盘焦点约束与关闭后焦点返回。
- 46 px 顶栏与吸顶上下文栏提供作业、Study、分析、文件四入口、只读标识、刷新和搜索。
  首页恢复最近访问 Study；不存在或无法读取偏好时取列表第一项。
- 旧 hash 用 replaceState 定位同一对象，保留 hash 内和 hash 前的参数，包括旧集合
  ensembleScope。返回链接记录浏览器历史中的来源、筛选和滚动位置；排序在本机记忆。
  从作业、概览或集合进入 Attempt 后可回到对应来源，刷新详情后仍可返回。
- 搜索覆盖已读取 Study 中的 Attempt 编号、标签、结构与分析文件、study.md，
  以及已读取 Attempt 的输入、日志、manifest、status、facts、review 和最终结构。
  输入关键词只查内存索引；选择文件时才读取并定位目标。不存在的精确文件明确报错。
- 原有页面保持完整。组件内样式迁移为全局类，颜色和字号引用令牌；分子元素、坐标轴
  的专用颜色保留。测距辅助线不再拦截原子点击，IRC 原子高亮通过数据属性和全局类实现。

页面内容仍为现有结果、监控快照和报告；本次不包含 T95 的概览 KPI、T96 的事实卡
与动作抽屉、T97 的容量条或 T98 的报告摘要和快速比较。
Python 适配器、只读限制、路径与大小检查、动作接口及 ag 确认流程未改动。
