# T98a：快速比较中的终止状态与虚频数

来源：T98 PR #22 的非阻塞建议，以及负责人 2026-10-17 指定的后续前端单。
基于 T97、T98 合并后的 `e38d978` 开发。全部示例为临时合成水 / 正丁烷与虚构能量。

## 显示规则

- Attempt 后固定显示 `termination`、`n_imag`；直接读取本次已加载的 `facts.json`。
- `termination` 显示非空字符串原文；`normal` 使用 neutral、`error` 使用 bad、其他已保存状态使用 warn。缺失、空白或类型无效显示 `—`。
- `n_imag` 显示已保存的非负安全整数，包括 `0`；缺失或无效值显示 `—`，采用现有 numeric 类右对齐与等宽数字。
- 字段仅供人工检查，不从 Attempt 状态、频率数组或能量补推，不参与比较口径拒绝或相对能量计算。已有非正式结果标题与“工具记录，待人工审阅”保持不变。
- 沿用 DataTable、StatusBadge、Drawer 和现有视觉令牌。比较抽屉使用视口相对宽度容纳七列，其余抽屉保持原有布局；没有新增令牌或组件内样式块。

## 验证

- 相关测试 22 项通过：normal / error / incomplete / unknown、缺失与无效字段、零与正虚频数、不回退到 status 或频率列表、原有能量差及口径拒绝、只读 HTTP 请求。
- TypeScript 检查与 Vite 生产构建通过。
- Python 全量离线 107 项、浏览器全量 137 项通过；CI 结果见 PR。
- 两个视口严格断言表格及全部七列表头完全可见，页面、抽屉与表格均无横向滚动；字体与内容没有缩减。
- Python 适配器、后端、动作确认、固定参数、锁及超时未修改。没有运行真实计算或连接集群；合并由负责人操作。
