# 前端改版总规格（T94–T98 共用）

> 前端仓库 `Auto-Gaussian-Frontend`。负责人 10-17 决定（四轮讨论）。各工单只实现自己那一部分，但都必须遵守本规格。本文件随 T94 放进前端仓库 `docs/redesign-v5.md`，后续工单引用它。

## 1. 目标

- **关键内容一屏放得下，其余折叠；突出对计算关键的信息。**
- 基准视口：**1440 × 860**（MacBook 14 寸浏览器可视区域）；最小保证 **1280 × 720** 不出现横向滚动、关键卡片不被挤出第一屏。
- 浅色主题。风格：介于“紧凑科研工作台”和“宽松卡片”之间、偏紧凑——**关键数值大而醒目，其余紧凑**。
- 改信息结构 + 统一外观；不重写数据读取、校验和安全边界（现有 Python 适配器、只读限制、路径检查、动作经 ag 的流程全部保留）。

## 2. 向 V3 学的东西（前端仓库提交 `83184af` 及之前，`docs/navigation-workspace.md`、`style.css`、`density.css`、`focused-layout.css`、`compact-science.css`、`navigation.css`、`monitor.css`）

只借鉴设计和交互，不恢复 V3 的功能代码、数据模型或执行入口。

1. **任务导向的少量顶层入口**（V3 从 12 个合并为 4 个）。
2. **详情页默认就是“科学阅读面”**：摘要、条件、结构、频率在同一屏；执行诊断、来源记录另放。
3. **统一的视觉令牌**：V3 用 `:root` 变量（主色 `#702879`、正文 `#282334`、次要 `#73637f`、分隔 `#e6ddec`、浅底 `#f7f1fa`）；紧凑尺寸：顶栏约 46 px、面板内边距 12–14 px、圆角 7 px、正文 12–13 px、次要 10–11 px。
4. **KPI 小卡**：上边框用主色强调，数字 24–25 px、`font-variant-numeric: tabular-nums`。
5. **状态小标签**：fresh / stale / partial / unavailable 各有固定配色（绿、琥珀、琥珀、红）。
6. **吸顶的上下文栏**（面包屑：Study / Attempt），“返回列表”保留筛选和滚动位置。
7. **表单和次要操作用右侧抽屉**（原生 `<dialog>`，Esc 关闭、焦点归还）。
8. **事实可定位到证据**：关键事实点击后跳到日志对应行（V3 的 onLocate）。
9. **旧链接兼容**：旧 hash 用 `replaceState` 跳转，保留查询参数，不在浏览器历史里多留一条。

本次主色**不必沿用紫色**：用一套新的克制配色（建议深青或深蓝为主色，与当前顶栏延续），但令牌结构、尺寸、KPI 和状态标签的做法照 V3。

## 3. 视觉令牌（T94 定义，之后所有页面只用这些）

- 颜色：`--accent`、`--accent-soft`、`--ink`、`--muted`、`--line`、`--surface`、`--surface-soft`；状态：`--ok`、`--warn`、`--bad`、`--info`、`--neutral`（各配前景 / 背景）。
- 字号：`--fs-xs 11px`、`--fs-sm 12px`、`--fs-md 13px`、`--fs-lg 16px`、`--fs-kpi 24px`；数字一律等宽数字。
- 间距：4 / 8 / 12 / 16 / 24；圆角 7 px；面板内边距 12 px。
- 组件（统一类名，写在全局样式表，禁止在组件里写 `<style>` 或大段内联样式）：`Panel`、`KpiTile`、`StatusBadge`、`FactGrid`（标签 / 值 / 可选来源定位）、`DataTable`（紧凑行高、吸顶表头、可选列）、`Collapsible`（带记忆）、`ActionBar`、`Drawer`、`EmptyState`、`ErrorNotice`。
- 状态语义映射（全站一致）：运行 / 排队 = info；完成 = ok；出错 / 未收敛 / 不匹配 = bad；待审 / 待签 / 过期 / unknown = warn；只读说明 = neutral。**“工具核对完成，待人工审阅”一律用 warn 或 neutral，不用 ok 绿色。**

## 4. 信息结构

顶栏（吸顶，约 46 px）：产品名 · 四个入口 · 全局搜索框 · 只读 / 可操作标识 · 刷新。

| 入口 | 内容 | 默认 |
|---|---|---|
| **作业**（第一个） | 各集群容量条；本人运行 / 排队 / 刚结束待取回的作业表 | |
| **Study** | 左侧 study 列表（可折叠）；主区：概览 / Attempt 表两个分区 | **首页**：进入最近在做的 study 的概览 |
| **分析** | 当前 study 的全部分析报告，按类型分组，每份一行结论；点进详情页 | |
| **文件** | 研究说明全文、结构文件、关系图、其余 analyses 文件 | |

吸顶上下文栏：`Study 名 / Attempt 编号`（或 `/ 分析报告名`），右侧“返回列表”（保留筛选和滚动位置）。

## 5. 各页面第一屏

**作业页**：顶部每个集群一条容量条（运行、排队、本人上限，数据新鲜度标签；过期醒目）。下方作业表，每行：Attempt（链接）、study、集群、状态、核数、已用 / walltime 进度条、最近快照进度（T84：第几步优化、最后 SCF 能量、快照时间）。可选粗估剩余时间，必须标“粗估”。

**Study 概览**：
- 一行 KPI：当前阶段 / 里程碑、在跑作业数、待审数、待签数；
- 左栏“要处理的事”：study.md 的“当前阻塞”“待你决定”两节条目 + 算完未审的 Attempt + 未签里程碑，每项可点；
- 右栏“关键结果”：最近更新的分析报告，每份一行结论；
- 折叠：研究说明全文、进度日志。

**Attempt 表**：默认列——编号、标签、类型、状态、方法缩写、电子能、自由能、虚频数、收敛；可展开列——集群、核数、用时、父 Attempt、提交时间。默认按编号倒序；筛选：状态、类型、“需要我处理”。勾选两个以上可开“快速比较”（见第 6 节）。

**Attempt 详情**：
- 上下文栏下面一条 **ActionBar**：只显示当前状态可用的操作；“取消”类危险操作用 bad 色、放最右。
- **左：关键事实卡**（FactGrid，关键数值用大号）——状态；方法 / 基组 / 溶剂；电荷 / 多重度；电子能、自由能；虚频个数与数值；优化与频率收敛（✓ / ✗）；用时 / walltime；警告。每个事实可点击定位到日志行。
- **右：三维结构**（现有查看器）。
- **下方折叠**：优化曲线、频率与虚频审阅、日志搜索、输入文件、来源与哈希、快照。

**分析入口**：按类型分组（构象集合、IRC、热化学 / 能量剖面、通道覆盖、TS 标签、NCI），每份报告一行：名称、更新时间、一句话结论（构象集合：候选数、分组数、最低者；IRC：两方向汇总状态；热化学 / 剖面：系综 G 或 ΔΔG‡ 与选择性；通道覆盖：是否不均衡；TS 标签：产物构型与待确认建议数；NCI：主要作用原子对）。点进去是现有详情页（改用统一组件）。

## 6. 快速比较（负责人决定：两种都要）

- 正式结论只认 ag 报告（分析入口）。
- Attempt 表勾选后的快速比较：前端现场计算相对电子能和自由能（kcal/mol，最低者为 0）；**先核对口径**——方法、基组、色散、溶剂、基函数形式、程序版本相同，元素组成、电荷、多重度相同（与后端 T82 规则一致），不一致就拒绝并列出差异；标题固定写“快速比较（前端计算，非正式结果）”；不做 Boltzmann、不换温度。

## 7. 交互

- 折叠状态按“页面类型 + 区块”记在浏览器本地（try/catch，读不到就用默认），不影响任何数据。
- 全局搜索：在本机已读取的 study 范围内按 Attempt 编号、标签、文件名搜索，直接跳转；不发远程请求。
- 旧链接：精确指向 Attempt、结构文件、分析报告的旧链接保持有效；旧标签页链接用 `replaceState` 跳到新位置。

## 8. 不变的东西

- 只读边界、路径检查、大小上限、动作经 ag 且提交 / 取消仍需 Mac 对话框——全部不变。
- 页面不出现“已验证”；工具状态不翻译成科学结论。
- 现有浏览器测试覆盖的功能在迁移后仍须可用（测试可以随页面结构改写，但覆盖的行为不能丢）。

## 9. 每张工单的视觉验收

- 在 1440 × 860 和 1280 × 720 两个视口截图（合成数据），写进 PR；Playwright 断言该页“第一屏必须可见”的元素（例如 Attempt 详情的关键事实卡和三维结构）在不滚动时完全可见。
- 不出现横向滚动；不出现未定义的 CSS 变量（加一条测试扫描）。
