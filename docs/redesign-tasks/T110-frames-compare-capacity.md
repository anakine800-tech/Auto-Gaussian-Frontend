## 要做的

### 1. 切换帧不跳动、视角保持（V1）

- 适用于所有可以切换帧的视图：优化轨迹、IRC 路径点、构象系综、扫描。
- 切换帧时三维视图**不重新挂载**，只更新坐标。相机的位置、缩放、旋转保持不变。容器高度固定，页面不发生滚动。
- 提供可选开关"对齐到参考帧"，默认关闭。打开后，按全部原子（原子数和元素顺序必须一致）做 Kabsch 刚体对齐，再显示当前帧。参考帧默认是第 1 帧，也可以指定。对齐只用于显示，不改动任何数据。元素顺序不一致时开关不可用，并说明原因。
- 回归测试：在 Playwright 中断言切换帧前后，`scrollY` 和相机参数都不变。

### 2. 任意结构对比（V2）

- 在 Attempt 表中勾选 2–3 个 Attempt，可以跨构象或跨物种，但必须在同一个 study 内，然后点"结构对比"。
- 打开并排视图，复用 T104 的三格组件：
  - 每一格显示：Attempt ID、最终几何、电子能（Hartree，保留 6 位小数）、虚频数、方法口径、跳转链接。
  - 相对能量：只有用 T98a / T103 的快速比较口径核对通过时才显示（kcal/mol，标注"前端计算、非正式"）；口径不同就写"口径不同，不给相对能"，并列出不同之处。
  - 对齐：可选"对齐到第 1 个"。要求原子数和元素顺序一致，否则开关不可用并说明原因。
  - 原子对：可以输入原子对（例如 `1-5,2-7`），在每一格高亮这些原子并列出距离（Å，注明前端计算）。
- 只读取 Attempt 已有的最终几何和 facts，不读其他文件，路径和哈希检查与现有规则一致。窄屏时改为纵向排列。

### 3. 排队上限等字段（V3）

- 作业页各集群卡片增加显示：
  - "排队 x / 排队上限 y"，只在有 `max_queued_cores` 时显示；
  - 单作业上限；
  - 运行加排队总上限；
  - 如果有 `scheduler_max_running_cores`，加注"由调度器执行，ag 未核实"。
- 缺少的字段显示"未提供"，不当作 0。

### 4. 集群容量总览（V4）

- 作业页顶部增加一张总览表，每个集群一行，列出：
  - 采样状态（新鲜 / 过期 / 失败，以及最后一次成功采样的时间）；
  - 本人运行核数、排队核数；
  - 总上限和剩余可提交核数（= 总上限 − 运行 − 排队，不小于 0）；
  - 排队上限；
  - 单作业上限；
  - 各档位的核数和内存（来自 T112 的 `tiers`，没有这个字段时显示"未知（后端未提供）"）；
  - PBS 集群如果快照里有节点信息，再列出空闲节点数和空闲核数。
- 同一账号共享上限的几个入口（`shared_with`）合并成一组显示，剩余核数只算一次。
- 标注："仅供参考；选择集群还需遵守 study 的平台规定（例如同一物种的优化与频率尽量放在同一集群）。"**不自动选择集群，不自动提交。**
- 采样失败或数据过期的集群，剩余核数显示为"未知"。

### 5. 令牌失效提示（V5）

- 开启了动作功能的页面，如果操作请求因令牌不匹配被拒（前端重启后会这样），显示"前端已重启，请刷新页面"，不要显示成一般性的错误。

### 6. 集群显示名（负责人 2026-10-23 补充）

- 集群卡片、容量总览表及作业列表：监控快照提供 `cluster.display_name` 时显示
  “显示名（入口名）”，没有时只显示入口名。示例：`scnet-初筛（scnet-test）`。
- 显示名与 T112 校验一致，为 1–32 个可打印字符；成功、失败快照均支持。
- 作业页卡片一入口一张，不合并；容量总览保留既有共享额度合组逻辑。
- 入口内部名称、manifest、台账文件名、作业号前缀不变。
- 两个视口各补一张截图；T112 合并前用合成快照验证显示名，不提前修改本机配置。

## 测试

| 场景 | 预期 |
|---|---|
| 优化轨迹 / IRC / 系综切换帧 | `scrollY` 和相机参数不变；容器高度不变 |
| 开启对齐到参考帧 | 显示对齐后的坐标；元素顺序不一致时开关不可用 |
| 勾选 2 个、3 个 Attempt 做对比 | 并排显示；能量、虚频数、链接正确 |
| 勾选 1 个或 4 个 | 对比按钮不可用 |
| 口径一致 / 不一致 | 一致时显示相对能，不一致时说明哪里不同 |
| 输入原子对 | 高亮，距离正确（用已知距离的夹具核对） |
| 快照含 `max_queued_cores` / 不含 | 正确显示 / 显示"未提供" |
| 含 `scheduler_max_running_cores` | 显示注释 |
| 总览表：共享入口 | 合并成一组，剩余核数只算一次 |
| 总览表：缺少 `tiers` | 显示"未知（后端未提供）" |
| 总览表：采样失败的集群 | 剩余核数显示"未知" |
| 令牌失效 | 提示刷新页面 |
| 1440×860、1280×720 两种视口 | 对比视图三格和总览表都在首屏完整可见（Playwright 断言，不加容差） |

全部离线测试、浏览器测试和构建各跑一次；做敏感信息扫描，并运行 `git diff --cached --check`。
