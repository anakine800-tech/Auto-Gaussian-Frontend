# T94–T98（前端）：前端改版，分五步

> 全部在**前端仓库** `Auto-Gaussian-Frontend` 开发，**开发机做**。设计依据见《前端改版总规格》（`FE-redesign-spec.md`，T94 时放进仓库 `docs/redesign-v5.md`）。按顺序做，**每一步合并后前端都必须完整可用**。每张一个分支、一个 PR，PR 描述第一行 `Task: T9x`。前端版本号这一轮不改，随下次发版。

## 共同规则

- 只用合成数据（虚构 study 名、公开小分子）；截图和测试中不出现研究 A、研究 B 或任何真实研究内容、路径、主机。
- 现有 Python 适配器、只读限制、路径与大小检查、动作经 ag 的流程一律不改行为；如必须改，停下询问。
- 测试范围：开发中只跑相关测试；首次开 PR 和合并前跑前端全部离线测试、浏览器测试和构建；复测只跑受影响部分加构建。
- 视觉验收按总规格第 9 节：1440 × 860、1280 × 720 两个视口截图附 PR；第一屏必须可见的元素用 Playwright 断言；无横向滚动；无未定义 CSS 变量。
- 停止条件（各单通用）：需要改后端 ag；需要改只读 / 动作的安全边界；现有测试覆盖的行为无法在新结构中保留。

## T94：视觉规范、顶层导航与框架、旧链接跳转、全局搜索

- 分支 `codex/t94-shell`。
- **要做：**
  1. 把总规格放进 `docs/redesign-v5.md`。
  2. 全局样式表实现总规格第 3 节的令牌和组件类；新增 `web/src/ui/`（或同等位置）放统一组件：`Panel`、`KpiTile`、`StatusBadge`、`FactGrid`、`DataTable`、`Collapsible`（折叠记忆）、`ActionBar`、`Drawer`、`EmptyState`、`ErrorNotice`。
  3. 新顶栏（作业 / Study / 分析 / 文件 + 全局搜索 + 只读标识 + 刷新）和吸顶上下文栏（面包屑 + 返回列表，保留筛选和滚动）。
  4. 新路由：`#/jobs`、`#/s/<study>`（概览）、`#/s/<study>/attempts`、`#/s/<study>/a/<attempt>`、`#/s/<study>/analysis`、`#/s/<study>/analysis/<类型>/<报告路径>`、`#/s/<study>/files/...`；旧 hash（`#server`、`#/<study>`、`#/<study>/<attempt>`、`#/<study>/structures|analyses/...`、`ensembles`、`irc-reviews`，以及查询参数）全部 `replaceState` 跳到新位置，精确链接指向同一对象。
  5. 首页：进入最近在做的 study 的概览（“最近”= 本地记住的上次访问 study；没有就取列表第一个）。
  6. 现有各页面先**原样挂到新框架下**（内容不重做，只换外壳和导航），保证功能完整。
  7. 全局搜索：本机已读取的 study 内按 Attempt 编号、标签、文件名搜索并跳转。
  8. 去掉各组件内的 `<style>` 和大段内联样式中与令牌冲突的部分（迁移到全局类）；把 `var(--line, …)` 这类未定义变量改成令牌。
- **设计检查点（重要）：** 框架完成后、开 PR 前，先在 PR 草稿里贴出 1440 × 860 下四个入口的截图，**请负责人确认外观方向**（配色、密度、字号）。负责人确认后再完成其余部分；不满意就先改令牌，不往下做。
- **测试：** 新旧路由全部可达；旧链接跳转后浏览器后退不被困住；搜索；折叠记忆读写失败时回退默认；无未定义变量。
