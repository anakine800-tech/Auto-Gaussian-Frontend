  - S1 页面第一屏：每台服务器一张**摘要卡片**；下方是**详情区**，用标签页切换服务器，点卡片也能切换；"刚结束待取回"放在页面最底部。
  - S2 卡片内容：名称（显示名）、调度器、状态（新鲜 / 非最新 / 采样失败）、采样时间距今、警告数；**核数和内存各一条分段进度条**，总长代表硬件总量，深色段 = 本人占用，浅色段 = 他人占用，空白 = 空闲，未知用斜纹；"运行 n 个作业 · 排队 m 个作业 / k 核"一行；"本人：运行 x · 排队 y / 总上限 z 核"一行；有共享上限时注明"与 ×× 共享总上限（只计一次）"。
  - S3 卡片顺序：按 `cluster.display_order` 排；为 null 时 PBS 在前、Slurm 在后，再按入口名排序。
  - S4 详情区：
    - 有警告时置顶显示，标签和卡片上显示警告数；数据非最新时整块加提示。
    - 作业表按"运行中 / 排队中"分组，每组标题写作业数和核数（运行中注明"核数为实际分配"，排队中注明"核数为申请值，按提交时间排序"）。
    - 列：用户、作业名、核数、内存、已运行 / walltime（带进度条和百分比，≥90% 用警示色）、队列；本人的行多显示 Attempt 链接和"最近快照进度"（沿用现有的 `SnapshotProgress`）。作业号放进可选列。
    - 本人作业置顶，行首加"本人"标签，行背景着色。
    - 表头右侧放"只看本人"开关，默认关；开关状态按服务器记在浏览器里（用 try/catch 包住，读不到就用默认值）。
    - Slurm 入口每组末尾加一行"其他用户：n 个作业 / k 核"，不显示用户名。
    - `cluster.jobs_omitted > 0` 时在表尾写"其余 n 条未列出"。
  - S5 "节点与队列"做成折叠区，默认收起，标题行写摘要（"空闲节点 x / 共 y · 空闲 z 核"）。节点表的列：状态、核数（已用 / 总，带小进度条）、内存（已分配 / 总）、作业数。Slurm 入口不列节点，只写一行分区 CPU 汇总。单节点的集群默认展开。
  - S6 "限额、档位与存储"做成折叠区，默认收起：ag 的三个上限、档位表、存储占用（KiB 换算成 GB，写查询时间和 `storage_error`）。档位和单作业上限只在这里出现。
  - S7 删除：现在的"集群容量总览"七列表、`ClusterCapacity` 卡片、底部按集群折叠的详情区、跨集群混排的"本人作业"表。
  - S8 采样间隔校验下限从 60 秒改为 30 秒；过期判定仍然是 3 倍间隔。
- **资料：** 后端 T114 工单第 6 节；`web/src/server-monitor.tsx`、`capacity-overview.tsx`、`jobs-data.ts`、`job-progress.tsx`、`autog_frontend/monitor.py`；`docs/ag-monitor-1.md`；前端改版规格 v6（随 T118 进入 `docs/redesign-v6.md`）。

## 要做的

1. **数据层**（`jobs-data.ts`）：把每个入口的快照整理成"卡片模型"和"详情模型"。进度条的各段在这里算好：本人 = `own` 中运行的核数和内存；他人 = 硬件已分配 − 本人；空闲 = 总量 − 已分配。任一项为 null 时整条显示为"未知"。共享组沿用 `capacityGroups` 的逻辑，本人占用只计一次。
2. **卡片**（`server-cards.tsx`）：按 S2、S3 实现。卡片是 `<button>`，带 `aria-pressed`；进度条要有 `role="img"` 和文字 `aria-label`（例如"核数：本人 44，他人 66，空闲 22，共 132"）。
3. **详情**（`server-detail.tsx`）：按 S4–S6 实现。标签页用 `role="tablist"`，可以用键盘左右切换。作业表复用现有的 `DataTable`。
4. **失败和过期的显示**：
   - 采样失败：卡片上的进度条变灰，数值写"未知"，并写上次成功的时间；
   - 只有硬件失败（`hardware.error`）：只把硬件条灰掉，本人数字照常显示，`error` 内容放进详情区；
   - 数据过期：照常显示，标"非最新"。
5. **校验器**：按 T114 第 6 节逐个字段校验类型和取值范围（`cores_kind` 只能是两种取值之一，秒数为非负整数，GB 为非负数或 null，ISO 时间可以解析）。未知字段照旧忽略。新字段缺失（旧快照）时，页面按"未知"显示，不报错。
6. **窄屏**：卡片自动换行；标签可以换行；表格在自己的框里横向滚动；整页不出现横向滚动。

## 不允许

- 不推算未知值，不把 null 画成 0。
- 不改 `main.tsx` 及路由；不改 Study、分析、文件相关页面。
