- **负责人 2026-10-23 决定（设计稿：前端改版规格 v6 第 1、2、3 节，原型第 2、3、7 屏）：**
  - N1 顶部导航改为：**服务器 / 研究 / 结果 / 证据**，右侧放"使用说明"。对应关系：服务器 = 原"作业"；研究 = 原"Study"（分区：进展、全部 Attempt；"计算链"分区由 T121 加入）；结果 = 原"分析"（分区：报告；"比较"分区由 T122 加入）；证据 = 原"文件"（现有标签先保持不变，由 T122 改版）。
  - N2 旧链接全部继续有效，用 `replaceState` 跳到新位置，不新增历史记录。
  - N3 去掉常驻的 Study 侧栏，改为上下文栏里的"Study ▾"切换器：可以筛选；分"研究"和"验证与测试"两组，后一组默认收起；最近打开的排在最前。
  - N4 study 类型：读 study.md 开头的 front matter 字段 `type: research|validation|test`（也接受中文 `类型: 研究|验证|测试`）；没有这个字段时，名称以 `val-`、`test-`、`demo-` 开头的归入"验证与测试"，其余归入"研究"。
  - N5 全局搜索覆盖本机**所有** study，由前端自带的本地后端建索引。只索引 study 名和标题、Attempt 编号、标签、模板、analyses 和结构文件的文件名；不索引文件内容，不发远程请求。
  - N6 进展页（原概览）：
    - 四个数字：在跑、待取回、待审阅、待签字，每个数字下面写明口径（见规格 v6 第 3 节），点击跳到对应列表。
    - "还缺什么"：有序清单，顺序为 当前阻塞 → 待取回 → 待审阅 → 待你决定 → 待签字；每一项写来源并带跳转。
    - 里程碑：每条给出明确状态——已签 / 待签 / 未开始 / 不适用 / 无法识别。"无法识别"附行号和原文链接。
    - "关键结果"改名为"最近改动的文件"，默认收起，并注明"只按修改时间，不代表重要性"。（"关键报告"和"当前采用的结果"由 T121 在有登记记录后加入。）
    - 研究说明和进度日志放在折叠区；进度日志只显示最近 3 条，其余折叠。
  - N7 "待审阅"的口径：study 有 T119 的登记记录（`catalog/state.json` 可读，并且 `journal_sha256` 与日志一致）时，只统计采用结果和候选对象所用的 Attempt；没有登记记录时，沿用现有规则，并把口径写成"尚无采用记录，按全部已取回的 Attempt 统计"。
  - N8 比较篮：固定在研究页和结果页底部；选择同时存在 sessionStorage 和 URL 参数 `cmp`（同一个 study 内，最多 6 项）；换页、看详情、回列表都保留。Attempt 表的勾选框和比较篮是同一份数据。"打开比较"暂时打开现有的快速比较和结构对比（T122 改成统一的比较页）。
  - N9 使用说明页 `#/help`：目录加各页的三栏说明（能看到什么 / 常用操作 / 数据从哪来）、状态口径表、可操作模式说明、页面不做的事。服务器页和报告页按 T115、T118 的实际内容写；计算链、比较、证据库写"将在 T121 / T122 完成"。

## 要做的

1. **导航与路由**（N1、N2）：路由表列出新旧路径的对应关系（在 PR 里附上这张表）。现有的浏览器测试里所有旧链接都要能跳到正确页面；返回列表时，筛选条件和滚动位置照旧保留。
2. **Study 切换器**（N3、N4）：弹出层有焦点管理，Esc 关闭，可以完全用键盘操作。最近打开的 study 记在浏览器里（用 try/catch 包住）。窄屏下切换器占满宽度。
3. **全局搜索**（N5）：
   - 索引在第一次搜索时建立，按各 study 的 manifest 和目录 mtime 判断是否需要更新；
   - 读取量有上限（单个 study 最多读取的文件数、总时长），超出时在结果里注明"索引未完成"；
   - 搜索结果最多 50 条，按 study 分组，可以直接跳转；
   - 搜不到时写"本机 study 中没有匹配的编号、标签或文件名"，不暗示"没有这个结果"。
4. **进展页**（N6、N7）：按设计稿实现。所有口径文字集中在一个常量文件里，使用说明页也引用同一份，保证两处一致。
5. **比较篮**（N8）：`compare-basket.ts` 是唯一的数据来源；URL 和 sessionStorage 不一致时以 URL 为准；超过 6 项时拒绝新增，并给出提示。
6. **使用说明**（N9）：内容是静态的，写在 `help-page.tsx` 里，不读任何文件。
