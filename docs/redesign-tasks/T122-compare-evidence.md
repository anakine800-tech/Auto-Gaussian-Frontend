# T122：前端统一比较页、证据库与来源关系

版本：v1（监督方，2026-10-24）。**开发机做。** 前端出一个 PR，PR 描述第一行写 `Task: T122 (frontend)`。

## 分支与目标

- 分支：`codex/t122-compare-evidence`。
- **开工条件：** 以前端 main（不早于 `a9695c5`）为基线。和 T121 并行开发，**T121 合并之后再 rebase、再合并**（两单都会动 `main.tsx`、`routing.ts`、`help-page.tsx`、比较篮的入口）。
- **负责人 2026-10-23 决定（前端改版规格 v6 的"结果 · 比较""证据库"两节，原型第 5、6 屏）：**
  - E1 **统一比较页**（结果 → 比较，路由 `#/<study>/compare`，选择以比较篮和 URL 参数 `cmp` 为准）。取代现在 Attempt 表上的"快速比较"和"结构对比"两个弹窗，原来的组件可以复用。页面包含：
    - **口径核对**：逐项写"一致 / 不同 / 缺失"——方法、基组、色散、溶剂、程序版本、元素组成、电荷、多重度（规则与现有快速比较、后端 T82 一致）；
    - **能量**：按层分开（Opt 层、SP 层），另列 ZPE、E+ZPE（近似 0–0）、G（公式与 T121 的 H4 相同）；参照项可选；口径不一致的格子留空并写原因；多重度不同时标"电子态能差"，不做布居；
    - **性质**：虚频数和最低虚频、⟨S²⟩、稳定性结论、优化与频率判据、审阅状态、来源 Attempt；
    - **几何**：用户填写的原子对距离（沿用现有原子对输入）；
    - **只看有差异的行**开关；
    - **结构叠合**：从比较篮中任选 2–3 个结构，Kabsch 对齐，显示 RMSD 和原子对距离（复用 T110 的实现）。
    - 标题固定写"比较（前端现场计算，非正式结果）"。
  - E2 比较篮里的条目属于某个已登记对象时（T121 的登记读取），能量各层取该对象被采用的 Opt / Freq / SP；不属于任何对象时，只用这个 Attempt 自己的 facts。
  - E3 **证据库**（证据 → 文件库）：
    - 每个文件只出现一次；左侧按类型分面：报告、表格、JSON、图片、HTML、结构、审阅意见（`review.md`）、签字记录、输入与日志；另可按关联的对象或 Attempt 筛选；
    - 列表列出：类型、关联对象 / Attempt、"被谁引用"、更新时间；右侧预览复用 T118 的文件查看组件；
    - "被谁引用"只统计 analyses 下 Markdown 里的本地相对链接，以及采用记录里的 `report` 字段；不分析其他文件的内容。
  - E4 **来源关系**：选择一个对象（未登记的对象按自动成链的结果），按行画出它的链和分支（例如 S0 一行，T1 从 S0 的结构分出来），框的颜色表示审阅状态，点框打开 Attempt。取代现在把全部 Attempt 排成一圈的关系图。
  - E5 证据下的**研究说明**沿用现有的 study.md 渲染（T118 起本地链接可以点）。原来"文件"下的四个标签（研究说明、结构文件、关系图、其他分析文件）合并进上面三个视图；旧链接用 `replaceState` 跳到新位置。
  - E6 顺带修三处小问题：
    - 服务器卡片上方加图例：深色 = 本人，浅色 = 他人，空白 = 空闲，斜纹 = 未知（T115 审阅 #1）；
    - 前端仓库加 `.githooks/pre-commit`（从后端复制，调用 `scripts/scan_public.py` 并读取本地词表；词表不进仓库），README 写明启用方法（T116 前端审阅 #1）；
    - 前端文档里的"研究用计算机"统一改为"研究用计算机"（T116 前端审阅 #2）；
    - 合入 T123 提供的 `docs/ag-monitor-1.md` 补丁（`job_summary_error`、`mem_source`），校验器同步加上这两个字段。T123 还没合并时，这一项先跳过，并在 PR 里注明。
- **资料：** `web/src/quick-comparison.ts`、`quick-comparison-panel.tsx`、`structure-comparison.tsx`、`geometry-alignment.ts`、`compare-basket.ts`、`compare-tray.tsx`、`study-panels.tsx`（`RelationshipGraph`）、`preview-panels.tsx`、`file-view.tsx`；`autog_frontend/studies.py`；前端改版规格 v6。
