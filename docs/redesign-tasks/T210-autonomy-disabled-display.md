# T210 自主取消与改投关闭时的展示

## 目标与范围

当前试点未启用自主取消和改投。有自主目录时，旧页面仍展示相关空表、
未知值和零值意图计数，容易使人误以为能力已启用。

本单从 `7df00876ebb71db04952a4fea5782fe2f3e29ec0` 开发，属于后续试点修补，
不纳入已冻结的 4.7.1 发布包，不改版本号或部署状态。

允许路径：

- `web/src/autonomy-view.tsx`
- `web/tests/autonomy.spec.ts`
- `docs/redesign-tasks/T210-autonomy-disabled-display.md`

## 行为

- 可读自主状态页直接显示“自主取消／改投未启用”。这是当前试点口径，
  不从版本、缺字段、空表、零计数或历史记录推断能力，也不新增能力协议。
- 移除取消、停止核验与改投的独立状态面板；本轮、单次唤醒、累计计数
  只展示 Attempt 意图与修复。已有取消和改投记录不删除、不重写。
- 最近日志事件仍按原规则展示保存的历史证据；历史取消请求受理或结果未知
  都不证明任务停止，也不构成当前能力启用或动作授权。
- 保留已结束失败作业的新 Attempt 补救记录、提交消费、等待记录、
  计划上限与已保存的暂停原因，不推算剩余预算。
- 无自主目录沿用“未启用”空态；读取失败、缺失、损坏及不支持版本仍明确
  无法核验，保持原有动作保护。手动按钮权限与后端/API 均不变。

后续启用自主取消或改投须另立工单。
